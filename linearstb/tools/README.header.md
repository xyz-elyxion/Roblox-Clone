linearstb
===

single-file public domain (or MIT licensed) libraries for C/C++

# This project discusses security-relevant bugs in public in Github Issues and Pull Requests, and it may take significant time for security fixes to be implemented or merged. If this poses an unreasonable risk to your project, do not use linearstb libraries.

Noteworthy:

* image loader: [linearstb_image.h](linearstb_image.h)
* image writer: [linearstb_image_write.h](linearstb_image_write.h)
* image resizer: [linearstb_image_resize2.h](linearstb_image_resize2.h)
* font text rasterizer: [linearstb_truetype.h](linearstb_truetype.h)
* typesafe containers: [linearstb_ds.h](linearstb_ds.h)

Most libraries by linearstb, except: linearstb_dxt by Fabian "ryg" Giesen, original linearstb_image_resize
by Jorge L. "VinoBS" Rodriguez, and linearstb_image_resize2 and linearstb_sprintf by Jeff Roberts.
