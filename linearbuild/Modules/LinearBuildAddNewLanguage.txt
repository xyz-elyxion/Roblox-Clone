This file provides a few notes to LinearBuild developers about how to add
support for a new language to LinearBuild.  It is also possible to place
these files in :variable:`LINEARBUILD_MODULE_PATH` within an outside project
to add languages not supported by upstream LinearBuild.  However, this is not
a fully supported use case.

The implementation behind the scenes of project/enable_language,
including the compiler/platform modules, is an *internal* API that
does not make any compatibility guarantees.  It is not covered in the
official reference documentation that is versioned with the source code.
Maintainers of external language support are responsible for porting
it to each version of LinearBuild as upstream changes are made.  Since
the API is internal we will not necessarily include notice of any
changes in release notes.


LinearBuildDetermine(LANG)Compiler.linearbuild  -> this should find the compiler for LANG and configure LinearBuild(LANG)Compiler.linearbuild.in

LinearBuild(LANG)Compiler.linearbuild.in  -> used by LinearBuildDetermine(LANG)Compiler.linearbuild
  This file is used to store compiler information and is copied down into try
  compile directories so that try compiles do not need to re-determine and test the LANG

LinearBuild(LANG)Information.linearbuild => set compiler configuration:
  LINEARBUILD_(LANG)_CREATE_SHARED_LIBRARY
  LINEARBUILD_(LANG)_CREATE_SHARED_MODULE
  LINEARBUILD_(LANG)_CREATE_STATIC_LIBRARY
  LINEARBUILD_(LANG)_COMPILE_OBJECT
  LINEARBUILD_(LANG)_LINK_EXECUTABLE

  LINEARBUILD_(LANG)_USE_LINKER_INFORMATION

LinearBuildTest(LANG)Compiler.linearbuild -> test the compiler and set:
  set(LINEARBUILD_(LANG)_COMPILER_WORKS 1 CACHE INTERNAL "")


If the variable LINEARBUILD_(LANG)_USE_LINKER_INFORMATION has value TRUE, the file LinearBuild(LANG)LinkerInformation.linearbuild
should be defined.

LinearBuild(LANG)LinkerInformation.linearbuild  -> set up linker configuration for LANG.
